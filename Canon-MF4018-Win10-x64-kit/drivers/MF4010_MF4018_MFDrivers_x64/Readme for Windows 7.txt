***********************************************************************************
When Using Windows 7
***********************************************************************************

You can use the software included in this CD-ROM with Windows 7.

For instructions on how to install each software package, refer to the manual 
provided with the printer.


Cautions
========
When using the printer driver with Windows 7, take note of the following cautions 
and limitations.

* Depending on the printer model you are using, you may not be able to install 
  the printer driver correctly in Windows XP Mode.
* The following software included in the CD-ROM does not operate in Windows 7.
  - UFRII LT XPS printer driver
  - WIA Network ScanGear
